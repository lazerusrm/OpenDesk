Enrollment tokens

For people you are talking to, use Onboard codes: they open /onboard and type a six-digit code from your phone. This page is the longer token/link flow.

Create a labeled, revocable token, then send the onboard URL. The recipient does not sign in and does not get access to other computers. The installed device is visible to you (administrators still see every device).

Official clients can also run rustdesk --deploy --token TOKEN against the configured API server. OpenDesk native check-in remains POST /api/enrollments/check-in.

Prefer the onboard URL when sending a link. Revoke the token if a link leaks. Set an expiry for links you send to people.
